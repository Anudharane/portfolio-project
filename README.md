# Dynamic Portfolio Website with Admin Dashboard

A complete, production-ready **Dynamic Portfolio Website** where all content is managed dynamically through a secure Admin Dashboard. No data is hardcoded — every section is controlled through the dashboard and stored in a database.

---

## 🚀 Technologies Used

### 💻 Frontend

* HTML5
* CSS3
* JavaScript (ES6)
* AOS (Animate on Scroll Library)
* Typed.js (Typing Animation Effect)

---

### ⚙️ Backend & Database

* Server-side scripting for handling requests
* Database for storing dynamic content
* Local development environment (XAMPP)

---

### 🔐 Security

* Authentication system for admin access
* CSRF protection
* Session management
* Input validation and sanitization
* Protection against common web vulnerabilities

---

## 🌐 Features

### Public Frontend

* Fully dynamic content loaded from database
* Responsive design for all devices
* Dark/Light mode toggle
* Smooth animations and transitions
* Interactive UI components
* Contact form with real-time response
* SEO-friendly structure

---

### 🛡 Admin Dashboard

* Secure login system
* Full content management (CRUD operations) for:

  * Hero Section
  * About Section
  * Skills
  * Education
  * Experience
  * Projects
  * Certificates
  * Services
  * Contact Information
  * Social Links
* Message management system
* File uploads (images, documents, resume, logo)
* Dashboard statistics and overview

1. Copy project folder to:


2. Start server services

3. Open database manager:

```id="6f2l7n"

```

4. Create database:


5. Import database file from project
